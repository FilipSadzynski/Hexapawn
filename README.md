# Hexapawn
MainWindow.xaml is the interface of the game. It consists of the 3x3 hexapawn board, the button start and points for our and computers side
you win by taking all of the opponents pieces or by having your piece reach the end of the board
MainWindow.xaml.cs consists of all the functions running the game
pozycje.txt is all of the responses to possible board states. first is the board position and after "/" are all of the responses whitch are deleted when they lead to a won game by the player
